# AI 한 접시

AI를 쉽고 가볍게, 그러나 정확하게.

공개·미리보기 채널은 Blogger로 단일화하는 운영 계약을 따릅니다. 이 GitHub 저장소는 발행 코드·편집 규칙·운영 문서의 버전관리 용도로 보존하며, GitHub Pages를 독자용 공개/이미지/미리보기 호스트로 사용하지 않습니다. 실제 전환 상태는 승인된 종료 기록과 운영 재조회로 확인합니다.
