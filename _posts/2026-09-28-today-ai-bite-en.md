<p class="post-kicker">Daily AI Bite</p>
<h1>September 28, 2026</h1>
<blockquote>This issue looks at AI extensions becoming reviewable plugins, helping non-developers build work tools, and connecting documents, apps, and automation in one workspace.<br />As these systems become more capable, people still need to check availability, data access, permissions, and review points.<br /></blockquote>

<h2>1. Anthropic opened a path to build and review plugins for Claude. <a class="source-badge" href="https://claude.com/blog/build-plugins-for-claude">Anthropic announcement</a></h2>
<p class="multi-sentence">On September 25, Anthropic introduced a path for building Claude plugins and submitting them to its directory.<br />Plugins can package MCP connectors and Agent Skills, and developers can submit either a remote MCP server or a repository bundling MCP servers and skills through the submission portal.<br /></p>
<p class="multi-sentence">The submission flow includes automatic validation and safety scanning, review status and feedback, and the option to choose when to publish after approval.<br />Anthropic also described usage analytics for installs by product surface and version after publication.<br /></p>
<ul><li><strong>Who it may help:</strong> Developers and organizations connecting Claude to internal tools and data.</li><li><strong>Current status:</strong> The submission portal is open to developers on paid Claude plans, and directory listings go through an approval process.<br /></li><li><strong>Why it matters:</strong> AI extensions are becoming a distribution unit with review, publishing, and usage analytics rather than only a personal configuration.<br /></li><li><strong>What to watch:</strong> Limit the data and permissions available to MCP servers and plugins. Automated safety scanning should not replace an organization’s own security review.<br /></li></ul>

<h2>2. OpenAI presented Codex as a custom work-building tool for a non-developer. <a class="source-badge" href="https://openai.com/index/proaction/">OpenAI customer story</a></h2>
<p class="multi-sentence">On September 25, OpenAI published a customer story about Proaction, a company that builds fleet-management software.<br />Proaction’s co-founder described using Codex to create interactive demos tailored to a prospect’s vehicles and workflows, using context from call recordings, email threads, and spreadsheets.<br /></p>
<p class="multi-sentence">According to OpenAI’s account, Proaction uses Codex plugins to bring together several work tools and reduce engineering time spent on demos.<br />Those time and sales figures are Proaction’s own estimates, not independent evidence that every team will see the same result.<br /></p>
<ul><li><strong>Who it may help:</strong> Small teams turning repeated work into custom demos, documents, or automations.</li><li><strong>Current status:</strong> This is an OpenAI-published customer story. Codex features, plugins, and access conditions may vary by account and product environment.<br /></li><li><strong>Why it matters:</strong> Coding tools are being positioned not only for developers, but also for sales, support, and product work.<br /></li><li><strong>What to watch:</strong> Teams should review permissions and privacy before connecting recordings, emails, or customer material. Company-reported savings and sales results are not independent validation.<br /></li></ul>

<h2>3. Microsoft grouped conversation, documents, app building, and automation inside Copilot. <a class="source-badge" href="https://blogs.microsoft.com/blog/2026/09/25/introducing-the-new-copilot-with-home-code-and-autopilot/">Microsoft announcement</a></h2>
<p class="multi-sentence">On September 25, Microsoft introduced Home, Code, and Autopilot as parts of a new Copilot experience.<br />Home brings Chat and Cowork together, Code lets people describe and build small work tools such as dashboards and automations, and Autopilot is described as an agent that continues defined work while a person is away.<br /></p>
<p class="multi-sentence">Microsoft also introduced Office in Copilot for creating and editing Word, Excel, and PowerPoint files inside Copilot.<br />Microsoft said Home and Code would roll out through its Frontier program, while Autopilot would expand to private preview at the end of September.<br /></p>
<ul><li><strong>Who it may help:</strong> Individuals, teams, and organizations connecting document work with repeated tasks in Microsoft 365.</li><li><strong>Current status:</strong> Some capabilities are in the Frontier program or preview, and availability and permissions differ by feature.<br /></li><li><strong>Why it matters:</strong> It shows a direction in which AI is becoming a workspace for creating documents, apps, and automations rather than only a question-and-answer window.<br /></li><li><strong>What to watch:</strong> Organizations should limit which files, channels, and workflows an agent can access, and people should review automated results before they become work output.<br /></li></ul>

<h2>Today in one sentence.</h2>
<p class="summary">These announcements show AI becoming more natural in conversation, more useful for building work, and more persistent in carrying tasks forward.<br />To use that convenience responsibly, define data permissions and human approval points before focusing on capability alone.<br /></p>
