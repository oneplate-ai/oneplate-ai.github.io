<p class="post-kicker">오늘 AI 한입</p>
<h1>2026년 9월 23일</h1>
<blockquote>이번 호는 AI를 더 저렴하게 쓰는 방법, 개발 도구에서 모델을 고르는 방법, 시민 의견을 넓게 듣는 방법을 살펴봅니다.<br />기능이 늘어날수록 가격·접근 권한·사람의 검토를 함께 확인해야 합니다.<br /></blockquote>

<h2>1. OpenAI가 GPT-6 Sol과 Luna를 공개했습니다. <a class="source-badge" href="https://openai.com/index/introducing-gpt-6-sol-and-luna/">OpenAI 공식 발표</a></h2>
<p class="multi-sentence">OpenAI는 9월 22일 GPT-6 계열의 새 모델인 Sol과 Luna를 발표했습니다.<br />두 모델은 GPT-6 Astra의 기술을 더 빠르고 저렴한 모델에 적용하는 방향으로 소개됐으며, OpenAI는 API 가격이 GPT-5.6의 프로모션 가격보다 50% 낮아졌다고 설명했습니다.<br /></p>
<p class="multi-sentence">GPT-6 Sol은 복잡한 업무와 코딩을 위한 균형형 모델로, Luna는 더 작고 빠른 작업을 위한 비용 효율 모델로 설명됩니다.<br />OpenAI가 제시한 성능·비용 비교는 회사 자체 평가이며, 다른 모델과의 우열을 독립적으로 확정하는 자료는 아닙니다.<br /></p>
<ul><li><strong>누구에게 해당하나:</strong> API로 AI 기능을 만드는 개발자와 반복적인 코딩·업무 작업을 하는 팀입니다.</li><li><strong>현재 상태:</strong> ChatGPT Work와 Codex에서는 Plus·Pro·Business·Enterprise·Edu 사용자를 대상으로 제공되며, Free·Go 사용자는 데스크톱 앱에서 Luna를 이용할 수 있다고 안내됐습니다. API에는 <code>gpt-6-sol</code>과 <code>gpt-6-luna</code>로 제공되며 순차 배포 중입니다.<br /></li><li><strong>왜 중요한가:</strong> 성능만 높이는 것이 아니라 사용량과 비용을 고려해 모델을 선택하는 흐름이 강해지고 있기 때문입니다.<br /></li><li><strong>주의할 점:</strong> 실제 이용 가능 여부와 한도는 계정·제품·배포 시점에 따라 달라질 수 있고, 가격·벤치마크 수치는 공개 직전에 다시 확인해야 합니다.<br /></li></ul>

<h2>2. GitHub Copilot에서 GPT-6 Sol·Luna와 Claude Opus 5.5를 선택할 수 있게 됐습니다. <a class="source-badge" href="https://github.blog/changelog/2026-09-22-openais-gpt-6-sol-and-gpt-6-luna-now-available/">GitHub 공식 변경 안내</a></h2>
<p class="multi-sentence">GitHub는 9월 22일 Copilot에 OpenAI의 GPT-6 Sol과 GPT-6 Luna를 추가했다고 발표했습니다.<br />Sol은 대화형·에이전트형 코딩을 위한 균형형 모델, Luna는 더 작고 빠른 작업을 위한 비용 효율 모델로 안내됐습니다.<br /></p>
<p class="multi-sentence">같은 날 GitHub는 Anthropic의 Claude Opus 5.5도 Copilot에서 제공한다고 밝혔습니다.<br />사용자는 모델 선택기에서 작업에 맞는 모델을 고를 수 있지만, 각 모델의 사용량 기반 과금과 요금 조건을 확인해야 합니다.<br /></p>
<ul><li><strong>누구에게 해당하나:</strong> GitHub Copilot을 사용하는 개발자와 조직 관리자입니다.</li><li><strong>현재 상태:</strong> Sol은 Pro+·Max·Business·Enterprise, Luna는 Pro·Pro+·Max·Business·Enterprise에서 제공되며, Opus 5.5는 Pro+·Max·Business·Enterprise에서 제공됩니다. 모두 순차 배포 중이고 일부 기능은 요금제별로 다릅니다.<br /></li><li><strong>왜 중요한가:</strong> AI 코딩 도구를 하나의 고정된 모델로 쓰지 않고 작업 난도·속도·비용에 맞춰 조정할 수 있기 때문입니다.<br /></li><li><strong>주의할 점:</strong> 모델 선택지가 많아져도 생성된 코드의 품질·보안·라이선스를 사람이 검토해야 하며, 사용량 기반 비용이 발생할 수 있습니다.<br /></li></ul>

<h2>3. Google.org와 Jigsaw가 지방정부의 시민 의견을 AI로 분석하는 프로그램을 지원합니다. <a class="source-badge" href="https://blog.google/company-news/outreach-and-initiatives/google-org/sensemaking-ai/">Google 공식 발표</a></h2>
<p class="multi-sentence">Google.org는 9월 22일 Jigsaw의 Sensemaking AI를 지방정부가 활용할 수 있도록 새로운 파트너 프로그램을 지원한다고 발표했습니다.<br />Sensemaking AI는 시민들의 의견을 대규모로 모으고 공통된 요구나 주제를 찾아 정책 참고자료로 정리하는 오픈소스 도구 모음으로 소개됐습니다.<br /></p>
<p class="multi-sentence">Google은 켄터키주 볼링그린에서 주민 8,000명의 의견이 25년 성장 계획에 반영됐다고 설명했습니다.<br />이는 AI가 정책을 대신 결정한다는 뜻이 아니라, 사람이 많은 의견을 읽고 비교할 수 있도록 정리하는 사례입니다.<br /></p>
<ul><li><strong>누구에게 해당하나:</strong> 시민 의견을 수집하는 지방정부와 공공기관, 지역사회 의견을 분석하는 담당자입니다.</li><li><strong>현재 상태:</strong> Jigsaw 파트너 프로그램은 지방정부가 관심을 표현하는 방식으로 운영되며, Google은 운영 비용 없이 대규모 시민 대화를 진행할 수 있다고 안내했습니다.<br /></li><li><strong>왜 중요한가:</strong> 설문과 민원처럼 흩어진 의견을 정책 논의에 활용할 때 AI가 정리 도구로 쓰일 수 있음을 보여주기 때문입니다.<br /></li><li><strong>주의할 점:</strong> AI가 요약한 의견이 모든 주민의 목소리를 공평하게 대표한다고 단정할 수 없으므로 원자료·참여 편향·최종 정책 판단을 사람이 확인해야 합니다.<br /></li></ul>

<p class="summary">AI 활용이 넓어질수록 좋은 모델을 고르는 일만큼 비용, 접근 권한, 시민과 사용자의 목소리를 사람이 다시 확인하는 절차가 중요해집니다.<br /></p>
